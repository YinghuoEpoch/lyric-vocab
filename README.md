# 我的文库

**在你真正想读的英文里背单词。**

一个英文精读与复习工具。导入一本书或一段文本，长按取词做笔记，笔记自动汇成复习卡片。
安卓 App，Capacitor 打包。**[→ 下载最新 APK](../../releases/latest)**

## 为什么做这个

背单词软件给你一张词表，词是别人挑的，例句是编的，背完了合上软件就忘。

这个工具反过来：**词从你正在读的东西里来。** 你在读的那本书、那首歌、那篇文章，
遇到不认识的词就长按标一下，上下文本来就在那儿。复习的时候，
每张卡片背后是你读过的那一句。

> 项目名 `lyric-vocab` 是历史遗留 —— 最初只用来读歌词，后来扩到任意英文文本。

## 功能

### 读

- **导入** `.txt` / `.epub`；txt 按「第 N 章 / Chapter」自动分章
- **内置书库**：App 内直接搜索并下载古腾堡计划的免费英文书（美国站 + 澳洲站），
  版权已过期，合法免费
- **沉浸阅读**：两条顶栏、两条系统栏一起收起来，屏幕上只剩正文。
  平板横屏自动触发，手机手动
- **外观**：纸色三种、强调色五种、字号 12–24、三种字体

### 标

- **长按取词**，连续滑动可选多词
- 三种笔记共用一套模型：**单词**（音标／词性／释义）、**短语**（用法／搭配）、
  **句摘**（句型／翻译）。选句子时自动带上两端引号和句末标点
- 笔记一律按正文顺序排列，不用手动整理
- **笔记栏跟着正文滚** —— 读到哪儿，右侧栏就把那条笔记居中显示

### 听

三级兜底，优先级从高到低：

1. **词典真人录音**（真人发音，最自然）
2. **云端合成**（火山引擎，需自备配置）
3. **系统语音引擎**

录音缓存在本机，设置页可看占用、可清理。有些设备（比如鸿蒙平板上的兼容层）
一个语音引擎都没有，云端这条路就是为它们留的。

### 背

- 生词与句摘以卡片呈现，可遮英文或遮中文
- 左滑删除（划过 72px 松手弹确认）

### AI 辅助（可选，需自备 Key）

- **一键填充**：补全空白字段，不覆盖你已经写好的内容
- **一键划词**：全文找生词，可指定难度档与数量档
- 兼容任意 OpenAI 格式接口 —— DeepSeek、通义千问、智谱、Kimi、本地 Ollama 都行

> **Key 只存在你自己的设备上**，不上传，也不写进导出的备份文件。

### 存

- IndexedDB 本地存储，删除的东西进回收站，可还原
- **多设备同步**：经坚果云 WebDAV，手机和平板共用一份数据。
  三方合并（不是「谁后保存谁赢」），正文与索引分开存，一次同步约 30 KB
- 导出／恢复备份（JSON 单文件）

## 安装

到 [Releases](../../releases/latest) 下载 APK，直接安装。需要 Android 7.0 以上。

首次启动会有一份用户协议。AI 辅助和云端朗读要自备 Key，在设置里填 ——
**不填也能用**，取词、笔记、复习、内置书库都不依赖它们。

> 交互是照着触摸屏设计的，键盘鼠标下不好用；沉浸阅读、系统栏、键盘避让
> 这些都在原生那一层，所以**不提供网页版入口**。

## 开发

```bash
npm install
npm run dev                       # 开发服务器
npm test                          # 659 项单元测试，约 2 秒
npx tsc -b --force && npm run build   # 提交前必须通过
```

打包安卓 App 的三步见 [发布到手机.md](发布到手机.md)。

技术栈：React 18 + TypeScript + Vite + Tailwind，Capacitor 打包安卓，
localforage 存 IndexedDB，fflate 解 epub，dnd-kit 做文库列表拖拽，Vitest 跑测试。

### 项目约定

1. 每次改动开一条分支，打包 APK 在真机上验过才合并
2. **WebView 不是 Chrome。** 涉及语音、文件、分享、系统栏这些系统能力的，
   先在真机上验一个最小实现
3. 单元测试全过 ≠ 验证完成。界面改动要在浏览器里走一遍真实流程
4. 观感问题以实测数值为准，不凭印象改
5. 改平板就是改平板，别碰两边共用的地基

# 歌词学英语

通过歌词上下文记单词的 PWA 应用。

## 技术栈

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide Icons
- LocalStorage

## 运行

```bash
cd lyric-vocab
npm install
npm run dev
```

浏览器打开 http://localhost:5173

## 功能

- **左侧栏**：歌词本（文件夹），可新建/删除歌词本与单篇歌词
- **中间**：极简编辑器；粘贴中英混合歌词后自动区分英文（衬线 Playfair Display）与中文（无衬线）
- **单词笔记**：悬停高亮英文单词，点击弹出气泡填写音标、词性、释义；保存后单词显示下划线，再次点击可编辑
- **右侧栏**：生词板自动汇总当前篇/全部标记过的单词，点击可滚动到文中位置
- **移动端**：左右侧栏默认隐藏，通过顶部汉堡菜单与生词图标呼出

首次打开会自带示例歌词《Yesterday Once More》及两条示例笔记，可直接体验点击单词做笔记。

## 现在它是什么

不再只是歌词。**任何英文文本**都能导入来精读：小说、文章、字幕文本都行。
名字里的「歌词」是历史遗留。

跑在两个地方：

- **网页**（PWA，能装到桌面）
- **安卓 App**（Capacitor 打包，打包三步见 [发布到手机.md](发布到手机.md)）

主力场景是手机。所有交互都是按手指设计的。

## 变化最大的三处

**一、取词从「悬停 + 点击」改成「长按」。**
早期那套在手机上时灵时不灵，而且看不出哪些词可以点。现在长按一个词进入取词模式，
连着划过去可以选一整段。桌面端的并行逻辑已经删掉了。

**二、笔记从三种变成一种。**
现在有 **单词 / 短语 / 句摘** 三类标注，但底下是同一个模型：每条有一个
**永不改变的 id**，位置只是它身上的一个属性。所以你随便改正文，笔记不会串位、
不会丢；实在找不到原文了会标成「原文已删除」问你留不留，把词打回去它还会自己复活。

早期版本是拿「第几行第几个词」当身份的，正文一改就出事——那是 2026-08-28
那批 bug 的总根源。

**三、多了「复习」模式。**
和阅读并列的第二个模式。生词和句摘变成卡片，可以：

- 遮住英文或中文来背
- 拖拽调整顺序
- 左滑删除
- 点一下听发音

## 完整功能

**导入**
- `.txt` 和 `.epub`；epub 一本书 = 一个文库，一章 = 一篇
- txt 会按「第 N 章 / Chapter / Session」自动分章

**标注**
- 长按取词 → 填音标、词性、释义
- 连划多词 → 存成**短语**（用法/搭配）或**句摘**（句型/翻译）
- 划句子会自动带上两头的引号和句号

**AI 辅助**（需要你自己的 API Key，只存在本机，不上传、不进备份）
- **一键填充**：把空着的格子补上，只填空白、绝不覆盖你写的
- **一键划词**：让 AI 通读全文挑生词，可选难度档和数量档
- 接任何「OpenAI 兼容」的服务：DeepSeek、通义千问、智谱、Kimi、
  自己电脑上的 Ollama 都行

**发音**
- 优先用**词典的真人录音**（有道），机器合成只在查不到时兜底
- 录音会缓存在本机，设置里能看占用、能清
- 点单词卡、点句摘卡、长按取词都会读

**外观**（设置 → 阅读外观）
- **纸色** 三种：标准 / 青灰 / 暖白
- **强调色** 五种：琥珀 / 墨蓝 / 松绿 / 朱红 / 石墨
- 字号、字体（无衬线 / 衬线 / 圆体）

**数据**
- 存在 **IndexedDB**（早期的 localStorage 数据会自动迁移过来）
- 设置里可导出/恢复备份（一个 json 文件）
- 回收站：文库和文档删了先进回收站，可还原

## 技术栈（补充）

早期那份仍然成立，另外还有：

- **Capacitor** —— 打包成安卓 App，用到它的 TTS / 文件 / 分享 / 返回键
- **localforage** —— IndexedDB 的壳
- **dnd-kit** —— 拖拽排序（文库列表和复习卡片）
- **fflate** —— 解压 epub
- **Vitest** —— 测试

## 几条约定

给接手的人（包括以后的 AI）：

- **每次改动开一条分支**，打包 APK 在真机上验过，确认没问题才并回 `master`
- **「浏览器里能跑」不等于装进 App 还能跑**。WebView 不是 Chrome，
  凡涉及朗读、相机、剪贴板、文件、分享，先在真机上验一个最小版本
- **光跑单测不算验过**，改完界面要去浏览器里走一遍真实流程
- **观感的问题不要凭印象改**，去把数字量出来
- 进度和待办一律写进 [后续规划.md](后续规划.md)，别只留在对话里

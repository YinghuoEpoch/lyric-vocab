# 歌词学英语

通过歌词上下文记单词的 PWA 应用。

## 技术栈

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide Icons
- LocalStorage

## 运行

```bash
cd lyric-vocab
npm install
npm run dev
```

浏览器打开 http://localhost:5173

## 功能

- **左侧栏**：歌词本（文件夹），可新建/删除歌词本与单篇歌词
- **中间**：极简编辑器；粘贴中英混合歌词后自动区分英文（衬线 Playfair Display）与中文（无衬线）
- **单词笔记**：悬停高亮英文单词，点击弹出气泡填写音标、词性、释义；保存后单词显示下划线，再次点击可编辑
- **右侧栏**：生词板自动汇总当前篇/全部标记过的单词，点击可滚动到文中位置
- **移动端**：左右侧栏默认隐藏，通过顶部汉堡菜单与生词图标呼出

首次打开会自带示例歌词《Yesterday Once More》及两条示例笔记，可直接体验点击单词做笔记。

# 2026-09-02 更新

本节为当前版本说明。上文为早期版本文档，保留原文，不再维护。
各项改动的背景与取舍记录见 [后续规划.md](后续规划.md)。

## 概述

英文精读与复习工具。导入英文文本后逐词、逐句标注，并在复习模式下背诵。
早期仅面向歌词，现支持任意英文文本；项目名中的「歌词」为历史遗留。

## 运行环境

| 形态 | 说明 |
|---|---|
| 网页 | PWA，可安装至桌面 |
| Android | Capacitor 打包，构建步骤见 [发布到手机.md](发布到手机.md) |

交互按触摸设备设计，主要使用场景为移动端。

## 相对早期版本的重大变更

| 项目 | 早期版本 | 当前版本 |
|---|---|---|
| 取词方式 | 悬停高亮 + 点击 | 长按进入取词模式，连续滑动可选取多词 |
| 笔记身份 | 以坐标为键（`L0W2`） | 每条标注持有不可变 id，坐标降级为属性 |
| 标注类型 | 仅单词 | 单词 / 短语 / 句摘，共用同一模型 |
| 模式 | 仅阅读 | 阅读 / 复习 双模式 |
| 存储 | LocalStorage | IndexedDB（旧数据自动迁移） |
| 桌面端逻辑 | 与移动端并存 | 已移除 |

坐标即身份是 2026-08-28 一批缺陷的共同成因。改为不可变 id 后，
编辑正文不再导致标注错位；原文删除时标注标记为孤儿并提示处理，
原文恢复后自动重新挂载。

## 功能

### 导入

- 支持 `.txt` 与 `.epub`
- epub：一册对应一个文库，一个正文文件对应一篇文档
- txt：按「第 N 章 / Chapter / Session」自动分章

### 标注

- 长按取词，填写音标、词性、释义
- 连续选取多词，保存为短语（用法／搭配）或句摘（句型／翻译）
- 选取句子时自动纳入两端的引号与句末标点

### AI 辅助

需自备 API Key。Key 仅存于本机，不上传，不写入导出的备份文件。

- **一键填充**：补全空白字段，不覆盖已有内容
- **一键划词**：全文检索生词，可指定难度档与数量档
- 兼容任意 OpenAI 兼容接口（DeepSeek、通义千问、智谱、Kimi、本地 Ollama 等）

### 语音

- 优先使用词典真人录音，语音合成仅在无录音时兜底
- 录音缓存于本机，设置页可查看占用并清理
- 单词卡、句摘卡、长按取词均可发音

### 复习模式

- 生词与句摘以卡片呈现
- 支持遮罩英文或中文
- 支持拖拽排序、左滑删除

### 外观

设置 → 阅读外观：

| 项 | 可选值 |
|---|---|
| 纸色 | 标准 / 青灰 / 暖白 |
| 强调色 | 琥珀 / 墨蓝 / 松绿 / 朱红 / 石墨 |
| 字号 | 12–24 |
| 字体 | 无衬线 / 衬线 / 圆体 |

### 数据

- IndexedDB 存储，早期 LocalStorage 数据首次启动时自动迁移
- 设置页支持导出与恢复备份（JSON 单文件）
- 文库与文档删除后进入回收站，可还原

   须先在真机验证最小实现
